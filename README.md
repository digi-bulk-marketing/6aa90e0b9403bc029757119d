# Popeye Group Creator

Popeye Group Creator by Popeye Marketing.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/6aa90e0b9403bc029757119d/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Popeye Group Creator** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/6aa90e0b9403bc029757119d/releases/latest) and reinstall.
